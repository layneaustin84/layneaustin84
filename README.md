## ⚡ Who I am

I sit at the intersection of two disciplines that rarely talk to each other: **occupational safety** and **applied AI**.

- 🎯 **Graduate Safety Practitioner (GSP)** — BCSP-designated, specializing in occupational safety & health
- ⚓ **U.S. Navy veteran** — leadership and safety management across military, industrial, and manufacturing environments
- 📚 **M.S. in Occupational Safety & Health / Environmental Management** (in progress) — *Columbia Southern University*
- 🧠 I build **AI systems that take the paperwork out of safety** — risk assessment, compliance reporting, and incident analysis, running on local hardware so sensitive data never leaves the building

<br/>

## 🚀 Now building

| Project | What it does | Stack |
|---|---|---|
| **AI-assisted PDF automation** | Fills, validates, and cross-checks SSA, VA, and OSHA documentation so practitioners stop hand-keying the same data three times | Python · Node.js · Electron |
| **Local LLM stack** | Self-hosted inference on an RTX 5080 — RAG over safety standards, LoRA/QLoRA fine-tunes, vector search | Ollama · PyTorch · Qdrant · Hugging Face |
| **Agentic safety workflows** | Multi-step agents that read incident reports, pull the governing standard, and draft the corrective action | Claude Code · MCP · OpenClaw |
| **EHS × AI job scout** | An agent that scores job postings against a rubric and surfaces roles where safety domain knowledge meets AI engineering | Python · agentic pipelines |
